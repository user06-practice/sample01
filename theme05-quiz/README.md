# テーマ5 クイズアプリ

CSVファイルから問題を読み込み、4択クイズを出題して採点するアプリです。ファイル読み込み、recordによるデータ表現、リストの並べ替えを学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ05 単語帳・クイズ」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme05-quiz/
├── README.md         … この要求仕様書
├── quiz.csv          … 問題ファイル（サンプル10問）
└── src/quiz/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── QuizManager.java  … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/quiz/` に追加してください。

## 画面構成

- 上部：問題番号（例：3 / 10問）と問題文
- 中央：4つの選択肢ボタン
- 下部：正解・不正解の表示と「次へ」ボタン
- 結果画面：正解数、正答率、間違えた問題の一覧

## 問題ファイルの形式

このフォルダにある `quiz.csv`（UTF-8）に1行1問で書きます。1列目が問題文、2列目が正解、3〜5列目が不正解の選択肢です。サンプルとして10問入っています。

```csv
apple の意味は？,りんご,みかん,ぶどう,もも
Javaで整数を表す型は？,int,String,boolean,char
```

問題を追加・修正するときは、IntelliJ上で `quiz.csv` を開いて編集してください。Excelで保存すると文字コードが変わり、文字化けすることがあります。

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F5-01 | 問題の読み込み | 起動時に quiz.csv を読み込む（10問以上用意する） |
| F5-02 | 出題順のシャッフル | 問題の順番を毎回ランダムにする |
| F5-03 | 選択肢のシャッフル | 4つの選択肢の並び順を毎回ランダムにする |
| F5-04 | 正誤判定 | 選んだ答えの正誤を表示し、不正解なら正解も表示する |
| F5-05 | 結果表示 | 全問終了後に正解数・正答率・間違えた問題を表示する |
| F5-06 | ファイルエラー | ファイルが無い・形式が違う場合はメッセージを表示する |
| F5-07 | 再挑戦 | 結果画面から最初からやり直せる |

## 実装上の条件

- 1問分のデータは record（例：`record Question(String text, String answer, List<String> wrongs)`）で表す
- ファイル読み込みは `Files.readAllLines(Path.of("quiz.csv"))` を使う
- シャッフルは `Collections.shuffle` を使う
- 判定ボタンを押した後は、「次へ」を押すまで選択肢を押せなくする
- 読み込み・出題順・採点は画面クラスとは別のクラス（`QuizManager`）に書く

## 拡張要件

- 間違えた問題だけをもう一度出題する「復習モード」
- 問題をアプリの画面から追加し、CSVに保存する
- 1問ごとの制限時間（例：10秒）

## 受け入れ基準

- [ ] CSVの問題が全問出題される
- [ ] 起動するたびに、問題と選択肢の順番が変わる
- [ ] 正答率が正しく計算される
- [ ] quiz.csv を削除・改名して起動しても、アプリが止まらずメッセージが出る
