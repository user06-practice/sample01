# テーマ1 じゃんけんゲーム

コンピュータとじゃんけんをして、勝敗と通算成績を表示するアプリです。ボタンのイベント処理とenum・switch式を学ぶ最初の課題です。おみくじアプリを選んでもよく、その場合は下の「おみくじ版」の要件に従います。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ01 じゃんけん」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme01-janken/
├── README.md         … この要求仕様書
└── src/janken/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── JankenGame.java   … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/janken/` に追加してください。

## 画面構成

- 上部：コンピュータの手と、勝敗の結果を表示するラベル
- 中央：「グー」「チョキ」「パー」の3つのボタン
- 下部：通算成績（勝ち・負け・あいこの回数）

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F1-01 | 手を選ぶ | 3つのボタンのどれかを押すと、自分の手が決まる |
| F1-02 | コンピュータの手 | ボタンを押すたびに、コンピュータの手をランダムに決める |
| F1-03 | 勝敗判定 | 「勝ち」「負け」「あいこ」を判定して表示する |
| F1-04 | 手の表示 | 自分の手とコンピュータの手を、両方とも文字で表示する |
| F1-05 | 通算成績 | 勝ち・負け・あいこの回数を数えて表示する |
| F1-06 | リセット | 「リセット」ボタンで通算成績を0に戻す |

## 実装上の条件

- 手（グー・チョキ・パー）は enum で表す
- 勝敗判定は switch式（アロー構文 `->`）で書く
- 勝敗判定は画面クラスとは別のクラス（`JankenGame`）に書く

## 拡張要件

- 勝率（%）を表示する
- 3回先に勝ったほうが勝ちの「3本勝負モード」
- 手を文字ではなく画像（アイコン）で表示する

## おみくじ版

「おみくじを引く」ボタンを押すと、大吉・中吉・小吉・吉・凶のどれかをランダムに表示します。結果はenumで表し、結果ごとに一言メッセージを表示します。引いた回数と、各結果が出た回数を表示します。拡張要件は「大吉が出にくい確率設定」「今日の日付の表示」です。

おみくじ版を作る場合も、このフォルダをそのまま使ってかまいません（クラス名 `JankenGame` は `Omikuji` などに変更してよい）。

## 受け入れ基準

- [ ] 3つのボタンでじゃんけんができる
- [ ] コンピュータの手が毎回ランダムに変わる
- [ ] 9通りすべての組み合わせで、勝敗が正しく表示される
- [ ] 通算成績が正しく数えられ、リセットで0に戻る
