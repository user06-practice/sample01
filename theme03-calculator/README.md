# テーマ3 電卓

四則演算ができる、ボタン式の電卓アプリです。GridLayoutによる部品の配置と、多数のボタンのイベント処理、計算ロジックの分離を学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ03 電卓」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme03-calculator/
├── README.md         … この要求仕様書
└── src/calculator/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── Calculator.java   … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/calculator/` に追加してください。

## 画面構成

- 上部：入力中の数や計算結果を表示する欄（右寄せ）
- 下部：4列×5行のボタン（0〜9、小数点、＋ − × ÷、＝、C）

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F3-01 | 数字入力 | 0〜9のボタンで数を入力し、表示欄に表示する |
| F3-02 | 四則演算 | ＋ − × ÷ のボタンと＝で計算し、結果を表示する |
| F3-03 | 連続計算 | 「1 ＋ 2 ＋ 3 ＝」のように続けて計算できる（左から順に計算） |
| F3-04 | 小数点 | 小数を入力できる。1つの数に小数点は1つまで |
| F3-05 | クリア | Cボタンで表示と計算途中の状態をすべて消す |
| F3-06 | 0除算 | 0で割ったら「エラー」と表示し、アプリは止まらない |
| F3-07 | 表示の整え | 結果が整数なら「5.0」ではなく「5」と表示する |

## 実装上の条件

- 計算処理（演算子ごとの計算）は画面クラスとは別のクラス（`Calculator`）に書く
- 演算子は enum で表し、計算は switch式で書く
- ボタンはループで作成し、同じ処理を何度も書かない

## 拡張要件

- ±（符号反転）、%、1文字削除（バックスペース）ボタン
- キーボードの数字キー・演算子キーでも入力できる
- 計算履歴を画面の横に表示する

## 受け入れ基準

- [ ] 「12 ＋ 34 ＝」で46と表示される
- [ ] 「1 ＋ 2 × 3 ＝」で9と表示される（左から順に計算）
- [ ] 「1.5 × 2 ＝」で3と表示される
- [ ] 「5 ÷ 0 ＝」でエラー表示になり、Cで元に戻れる
