# テーマ2 数当てゲーム

コンピュータが決めた1〜100の数を、ヒントを頼りに当てるアプリです。入力値のチェックと例外処理、ゲームの状態管理を学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ02 数当てゲーム」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme02-number-guess/
├── README.md         … この要求仕様書
└── src/numberguess/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── NumberGuessGame.java … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/numberguess/` に追加してください。

## 画面構成

- 上部：説明文「1〜100の数を当ててください」
- 中央：数を入力するテキスト欄と「判定」ボタン
- 下部：ヒント（大きい・小さい）、残り回数、これまでに入力した数の履歴

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F2-01 | 正解の決定 | ゲーム開始時に、1〜100の正解をランダムに決める |
| F2-02 | 判定 | 入力した数が正解より大きいか小さいかを表示する |
| F2-03 | 正解表示 | 正解したら「正解！ ○回で当たりました」と表示する |
| F2-04 | 回数制限 | 挑戦できるのは10回まで。使い切ったら正解を表示してゲーム終了 |
| F2-05 | 入力チェック | 数字以外や、1〜100の範囲外を入力したらエラーメッセージを表示する（回数は減らさない） |
| F2-06 | 履歴 | 入力した数を順番に表示する |
| F2-07 | 再挑戦 | 「もう一度」ボタンで、新しい正解を決めて最初からやり直す |

## 実装上の条件

- 文字列から数への変換は `Integer.parseInt` を使い、`NumberFormatException` を try-catch で処理する
- ゲームの状態（プレイ中・正解・失敗）は enum で表す
- ゲーム終了後は「判定」ボタンを押せなくする
- 判定や回数の管理は画面クラスとは別のクラス（`NumberGuessGame`）に書く

## 拡張要件

- 難易度選択（1〜10、1〜100、1〜1000）と、難易度ごとの回数制限
- Enterキーでも判定できるようにする
- 最少回数の記録（ベストスコア）を表示する

## 受け入れ基準

- [ ] 大きい・小さいのヒントが正しく表示される
- [ ] 「abc」や「150」を入力してもアプリが止まらず、エラーメッセージが出る
- [ ] 10回外れると正解が表示され、判定できなくなる
- [ ] 「もう一度」で正解が変わり、回数と履歴がリセットされる
