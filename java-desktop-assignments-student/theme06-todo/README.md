# テーマ6 ToDoリスト

やることを追加・完了・削除でき、終了しても内容が残るToDoリストです。List によるデータ管理、JListの表示、ファイルへの保存と読み込みを学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ06 ToDoリスト」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme06-todo/
├── README.md         … この要求仕様書
└── src/todo/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── TodoList.java     … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/todo/` に追加してください。

## 画面構成

- 上部：やることを入力するテキスト欄と「追加」ボタン
- 中央：ToDoの一覧（完了したものは先頭に「[済]」を付ける）
- 下部：「完了にする」「削除」ボタンと、未完了の件数

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F6-01 | 追加 | 入力した内容を一覧の末尾に追加し、入力欄を空にする |
| F6-02 | 空入力の防止 | 空欄や空白だけの場合は追加せず、メッセージを表示する |
| F6-03 | 完了 | 一覧で選んだ項目を完了状態にする（もう一度押すと未完了に戻す） |
| F6-04 | 削除 | 選んだ項目を、確認ダイアログで「はい」を押したら削除する |
| F6-05 | 未選択時の操作 | 何も選ばずに完了・削除を押したらメッセージを表示する |
| F6-06 | 件数表示 | 未完了の件数を表示する |
| F6-07 | 保存 | 追加・完了・削除のたびに todo.txt へ自動保存する |
| F6-08 | 読み込み | 起動時に todo.txt を読み込む（ファイルが無ければ空の一覧で始める） |

## 実装上の条件

- ToDo 1件は record（例：`record Todo(String title, boolean done)`）で表す
- 一覧は `List<Todo>` で管理し、画面の表示は `DefaultListModel` で更新する
- 保存は `Files.writeString`、読み込みは `Files.readAllLines` を使う
- record は値を変更できないため、完了状態の切り替えは新しい record を作って置き換える
- 一覧の管理と保存・読み込みは画面クラスとは別のクラス（`TodoList`）に書く
- `todo.txt` はこのフォルダ（theme06-todo）の直下に作られます。Gitの管理対象からは除外されています

## 拡張要件

- 期限（日付）を付け、期限切れの項目を赤字で表示する（`java.time.LocalDate`）
- 「すべて」「未完了のみ」「完了のみ」の表示切り替え
- 項目のダブルクリックで内容を編集する

## 受け入れ基準

- [ ] 追加・完了・削除が一覧に正しく反映される
- [ ] 空欄では追加できない
- [ ] アプリを終了して再起動しても、内容と完了状態が残っている
- [ ] todo.txt が無い状態でも起動できる
