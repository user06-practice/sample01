# テーマ7 簡易メモ帳

テキストファイルを開いて編集し、保存できるメモ帳アプリです。メニューバー、ファイル選択ダイアログ、ファイル入出力の例外処理を学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ07 簡易メモ帳」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme07-memo/
├── README.md         … この要求仕様書
└── src/memo/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── MemoFile.java     … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/memo/` に追加してください。

## 画面構成

- 上部：メニューバー（「ファイル」メニューに 新規・開く・保存・名前を付けて保存・終了）
- 中央：文章を入力するテキスト領域（長い文章はスクロールできる）
- 下部：ステータスバー（文字数と行数）
- タイトルバー：「ファイル名 - 簡易メモ帳」（未保存の変更があれば先頭に「*」）

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F7-01 | 新規 | テキスト領域を空にして、新しい文書を始める |
| F7-02 | 開く | ファイル選択ダイアログで選んだテキストファイルを読み込んで表示する |
| F7-03 | 保存 | 開いているファイルに上書き保存する（新規の文書なら「名前を付けて保存」と同じ動作） |
| F7-04 | 名前を付けて保存 | ファイル選択ダイアログで保存先と名前を決めて保存する |
| F7-05 | 未保存の表示 | 内容を変更したら、タイトルバーの先頭に「*」を付ける |
| F7-06 | 文字数・行数 | 入力のたびに文字数と行数を更新する |
| F7-07 | 終了時の確認 | 未保存の変更がある状態で終了・新規・開くを選んだら、保存するか確認する |
| F7-08 | エラー処理 | ファイルの読み書きに失敗したらメッセージを表示する |

## 実装上の条件

- ファイル選択には `JFileChooser` を使う
- 読み書きは `Files.readString` / `Files.writeString`（UTF-8）を使い、`IOException` を try-catch で処理する
- 変更の検知には `DocumentListener` を使う
- テキスト領域は `JScrollPane` に入れる
- ファイルの読み書きと未保存状態の管理は画面クラスとは別のクラス（`MemoFile`）に書く
- ×ボタンで確認を出すため、`setDefaultCloseOperation` は `DO_NOTHING_ON_CLOSE` に変更し、`WindowListener` で終了処理を書く（スターターコードは `EXIT_ON_CLOSE` になっています）

## 拡張要件

- 文字の検索（見つかった位置を選択状態にする）
- フォントサイズの変更（メニューから大・中・小）
- Ctrl+S などのショートカットキー

## 受け入れ基準

- [ ] 保存したファイルをWindowsのメモ帳で開くと、同じ内容が表示される
- [ ] 編集すると「*」が付き、保存すると消える
- [ ] 未保存のまま×ボタンを押すと確認ダイアログが出る
- [ ] 文字数・行数が入力に合わせて変わる
