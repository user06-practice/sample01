# テーマ9 家計簿

日付・費目・金額を記録し、月ごとの合計を集計する家計簿アプリです。JTableによる表の表示、日付の扱い、Streamによる集計、CSVへの保存を学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ09 家計簿」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme09-kakeibo/
├── README.md         … この要求仕様書
└── src/kakeibo/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── Kakeibo.java      … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/kakeibo/` に追加してください。

## 画面構成

- 上部：入力欄（日付、収入／支出の選択、費目のプルダウン、金額、メモ）と「登録」ボタン
- 中央：記録の一覧表（日付・区分・費目・金額・メモ）
- 下部：表示する月の選択、その月の収入合計・支出合計・差額、費目別の支出合計、「削除」ボタン

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F9-01 | 登録 | 入力した内容を1件の記録として一覧に追加する |
| F9-02 | 日付の初期値 | 日付欄には起動した日の日付を最初から入れておく |
| F9-03 | 費目 | 支出は 食費・日用品・交通費・娯楽・その他、収入は 給料・その他 から選ぶ |
| F9-04 | 入力チェック | 日付が「2026-11-01」の形式でない、金額が正の整数でない場合はエラーメッセージを表示する |
| F9-05 | 月の切り替え | 選んだ月の記録だけを、日付の古い順に表示する |
| F9-06 | 月の集計 | 表示中の月の収入合計・支出合計・差額（収入−支出）を表示する |
| F9-07 | 費目別集計 | 表示中の月の、費目ごとの支出合計を表示する |
| F9-08 | 削除 | 一覧で選んだ記録を、確認後に削除する |
| F9-09 | 保存・読み込み | 登録・削除のたびに kakeibo.csv に保存し、起動時に読み込む |

## 実装上の条件

- 1件の記録は record（例：`record Entry(LocalDate date, EntryType type, String category, int amount, String memo)`）で表す
- 区分（収入・支出）は enum（例：`EntryType`）で表す。`Type` という名前にすると、JFrameを継承したクラスの中で `java.awt.Window.Type` と名前がぶつかってコンパイルエラーになるので使わない
- 日付は `java.time.LocalDate`、月は `java.time.YearMonth` で扱う
- 集計は Stream（`filter`、`mapToInt`、`sum`、`Collectors.groupingBy`）で書く
- 一覧表は `JTable` と `DefaultTableModel` で表示する
- 記録の管理・集計・保存は画面クラスとは別のクラス（`Kakeibo`）に書く
- `kakeibo.csv` はこのフォルダ（theme09-kakeibo）の直下に作られます。Gitの管理対象からは除外されています

## 拡張要件

- 費目別の支出を棒グラフで描く（`Graphics2D`）
- 月の予算を設定し、超えたら警告を表示する
- 金額を「1,234円」のように3桁区切りで表示する

## 受け入れ基準

- [ ] 登録した記録が一覧と合計に反映される
- [ ] 「2026/11/01」や「-500」「abc」ではエラーメッセージが出て、登録されない
- [ ] 月を切り替えると、その月の記録と合計だけが表示される
- [ ] 再起動しても記録が残っている
