# テーマ8 三目並べ

3×3のマスに○と×を交互に置き、縦・横・斜めのどれかを先に3つ揃えたほうが勝ちのゲームです。2次元配列による盤面の管理と、勝敗判定のアルゴリズムを学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ08 三目並べ」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme08-tictactoe/
├── README.md         … この要求仕様書
└── src/tictactoe/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── Board.java        … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/tictactoe/` に追加してください。

## 画面構成

- 上部：手番の表示（「○の番です」）や勝敗の結果
- 中央：3×3のマス（ボタン9個）
- 下部：「新しいゲーム」ボタンと、○の勝ち・×の勝ち・引き分けの回数

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F8-01 | 交互に置く | マスを押すと、手番のプレイヤーの印（○または×）を置き、手番を交代する（先手は○） |
| F8-02 | 置けないマス | すでに印があるマスは押しても何も起きない |
| F8-03 | 勝利判定 | 縦3列・横3行・斜め2本のどれかが揃ったら勝者を表示する |
| F8-04 | 引き分け判定 | 9マスすべて埋まって勝者がいなければ「引き分け」と表示する |
| F8-05 | 決着後の操作 | 勝敗が決まったら、残りのマスを押せなくする |
| F8-06 | 新しいゲーム | 盤面を空に戻して最初から始める |
| F8-07 | 戦績 | ○の勝ち・×の勝ち・引き分けの回数を表示する |

## 実装上の条件

- 盤面は2次元配列（例：`Mark[][] board = new Mark[3][3]`）で管理する
- マスの状態（空・○・×）は enum で表す
- 勝敗判定は画面クラスとは別のクラス（`Board`）に書く
- 9個のボタンはループで作成し、押されたマスの行・列がわかるようにする

## 拡張要件

- コンピュータ対戦（まずは空いているマスにランダムに置く）
- 揃った3マスの背景色を変えて強調する
- コンピュータを強くする（勝てるマスがあれば置く、相手が揃いそうなら防ぐ）

## 受け入れ基準

- [ ] ○と×が交互に置かれる
- [ ] 横・縦・斜めのすべての揃い方（8通り）で勝利と判定される
- [ ] 引き分けが正しく判定される
- [ ] 決着後はマスを押せず、「新しいゲーム」で再開できる
