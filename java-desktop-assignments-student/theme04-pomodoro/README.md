# テーマ4 ポモドーロタイマー

25分の作業と5分の休憩を交互に計るタイマーアプリです。javax.swing.Timer による一定間隔の処理と、時間の計算・画面更新を学びます。

## 実行方法

1. IntelliJ IDEA の右上にある実行構成の一覧から「テーマ04 ポモドーロタイマー」を選ぶ
2. 緑の実行ボタン（▶）を押す

スターターコードの状態では、タイトルだけが入った空のウィンドウが表示されます。ここに画面と機能を作っていきます。

## このフォルダの構成

```
theme04-pomodoro/
├── README.md         … この要求仕様書
└── src/pomodoro/
    ├── Main.java         … 起動用のクラス（基本的に変更不要）
    ├── MainFrame.java    … 画面を作るクラス（ここから作り始める）
    └── PomodoroTimer.java … 処理を担当するクラス（中身は自分で書く）
```

必要に応じて、クラス（enum・record を含む）を `src/pomodoro/` に追加してください。

## 画面構成

- 上部：現在のモード（「作業中」「休憩中」）
- 中央：残り時間を大きく表示（例：24:59）
- 下部：「開始」「一時停止」「リセット」ボタンと、完了した作業回数

## 必須要件

| ID | 機能 | 内容 |
| --- | --- | --- |
| F4-01 | カウントダウン | 「開始」で残り時間を1秒ごとに減らし、「分:秒」の形式で表示する |
| F4-02 | 一時停止・再開 | 「一時停止」で止め、「開始」で続きから再開する |
| F4-03 | リセット | 現在のモードの最初の時間に戻して停止する |
| F4-04 | モード切替 | 作業25分が終わったら休憩5分、休憩が終わったら作業に自動で切り替わる |
| F4-05 | 終了の通知 | 時間になったらダイアログとビープ音で知らせる |
| F4-06 | 回数表示 | 完了した作業の回数を表示する |
| F4-07 | モードの色分け | 作業中と休憩中で、残り時間の文字色を変える |

## 実装上の条件

- 1秒ごとの処理は `javax.swing.Timer` を使う（`Thread.sleep` は使わない）
- モード（作業・休憩）は enum で表し、それぞれの時間を enum に持たせる
- 時間の表示には `java.time.Duration` を使うか、秒数から分と秒を計算する
- 動作確認のため、時間を短く（例：10秒）変えられるよう定数で定義する
- 残り時間やモードの管理は画面クラスとは別のクラス（`PomodoroTimer`）に書く

## 拡張要件

- 作業・休憩の時間を画面から設定できる
- 4回作業したら15分の長い休憩にする
- 残り時間を円形のプログレス表示で描く

## 受け入れ基準

- [ ] 開始すると1秒ごとに表示が減る
- [ ] 一時停止→開始で、止めたところから再開する
- [ ] 時間を短く設定して、作業→休憩→作業と自動で切り替わることを確認できる
- [ ] 終了時にダイアログが表示され、作業回数が増える
